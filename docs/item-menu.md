# Item picker and mod menu

In an unpaused cleared room, hold both stick clicks and D-pad Down for two seconds. Release the buttons when the menu opens. The run stops while the picker is open.

- D-pad up/down: select an item.
- L/R or D-pad left/right: jump a page.
- ZL/ZR: jump to another starting letter.
- Y: filter all, passive, active, or familiar items.
- A: place one item on a clear nearby pedestal. Holding A never repeatedly places items.
- B: close, then release B to resume the run.
- X: switch between items and mods.

The main game menu after choosing a save also offers X: Mods. Mod switches currently last until Isaac is closed. They do not change game saves. The picker contains every collectible record in the user's exact 1.7.9b game data (721 entries); unused IDs are not offered. The game itself validates the selected item before creating it.

The picker is a testing tool. Selecting an item deliberately creates that item in the current run. It does not unlock items or rewrite the save file directly. Normal game saving still records the resulting run.
