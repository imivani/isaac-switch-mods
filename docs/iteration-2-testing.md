# Expanded pack: console checks

This package is for the verified US Switch Repentance 1.7.9b build only. A local
build and host tests do not establish that these new changes work on hardware.
The previous installed package has a separate, verified backup.

1. Fully close Isaac before copying files. Reopen it after installation.
2. Check the Planetarium percentage: its characters should match the normal
   stat list, with the same row spacing, both docked and handheld. Toggle the
   in-game stats display; the Planetarium row should follow it.
3. Fight Pin: one Pin should have one bar, and two distinct Pins should have
   two bars. Watch the portrait and health as Pin dives and reappears.
4. Visit a sacrifice room. Approach the spikes before using them, then check
   whether the text updates to the next payout after a sacrifice.
5. Check a dice room, cards/runes, an unknown pill and an already known pill.
   Unknown pills and blind item pedestals should not reveal hidden identities.
   Check the accompanying EID coverage document for additional supported cases.
6. Hold Map to view held items and character information. While holding Map,
   tap shoot left/right to move through the entries. Release Map to return to
   nearby descriptions. A nearby Flip or Glitched Crown preview can take
   priority over this reminder; see the special-feature notes for its controls.
7. With Flip, check an ordinary and an empty flipped pedestal. With Glitched
   Crown, check that the preview stays readable while the visible item cycles.
   Tainted Cain should receive salvage information for eligible pedestals.
8. Use a slot machine or coin beggar in a cleared room: hold towards it and
   wait for the gradual speed-up. Release the direction or walk away: speed
   should return immediately to normal. Check that the run timer also advances.
   The speed-up is capped at six times normal speed; enemies, fires, bombs and
   hostile projectiles keep the room at ordinary speed.
9. Test blood-machine/devil-beggar acceleration with ample health. The final
   heart should stay at ordinary speed. Pause, use a card/item, or leave the
   room: none should cause repeated uses or a continued speed-up.
10. Recheck an ordinary item description and a Regret pedestal afterimage.

Antibirth music and save files are outside this update's installation scope.
Keep exact installation hashes and each observed console result in the
deployment record. Do not mark all features tested from one successful launch.
