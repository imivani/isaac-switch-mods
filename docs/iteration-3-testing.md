# Test the new additions

This is a new test build for the exact installed US Switch Repentance 1.7.9b version. Local compilation and asset checks do not establish that it runs correctly on the Switch.

Fully close Isaac before copying the package. Use the prepared installer with DBI's MTP responder; it checks the installed version, retains rollback copies and reads the copied files back before reporting installation success. Do not mix these files with another game version.

1. Launch and continue a normal run. Check that existing EID, boss bars, Planetarium, Regret and music still work.
2. Hold Map and use left/right shooting directions to browse your character, held items, pocket items and collected items. Test handheld as well as docked if available. Release Map to return to nearby descriptions.
3. In a cleared room, hit an ordinary orange fire or poop once. It should break and keep its normal drops. A fire in a room with live enemies should retain normal behavior; colored fires are unchanged.
4. Check an item supported by Animated Items, both on its pedestal and while being held up after collection. The pedestal base, shop price and normal room positioning should remain intact. Items hidden by Curse of the Blind must stay hidden.
5. Find Birthright and check that its picture matches your character. Co-op uses the relevant nearby player.
6. Enter a room with a visible quality-four item. Check the Specialist dance and song, then collect or remove the item and confirm the usual music resumes. Check that shooting, movement, taking damage and room changes remain normal.
7. For a quick testing loadout, in a cleared room hold both stick clicks plus D-pad Down for two seconds. The game should spawn Brimstone, Tammy's Head, Sacred Heart, Holy Mantle, Pyromaniac and Car Battery as free pedestals. It should show the number placed. Holding longer must not create repeated batches; release all three buttons and wait ten seconds before another batch.

Stop and report any crash, missing image, repeated sound, duplicate spawning or control interference. Keep the prior package and installer rollback copies until these checks pass.
