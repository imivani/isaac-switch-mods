# Console checks for iteration 4

The user confirmed that the installed update works after testing on the Switch. These steps are retained as a repeatable checklist; the feedback was an overall confirmation, not a separate record of every edge case.

1. On the main menu after selecting a save, press X. Check that Mods opens, A changes a switch, and B returns without starting a run.
2. In a cleared room, hold both stick clicks + D-pad Down for two seconds, then release. Verify the run stops while the item picker is open.
3. Select Breakfast and Psy Fly (sometimes called SciFly), press A once for each, and close with B. Verify visible animated pedestal icons and pickup pictures.
4. Check page, letter and type filters. Holding A must create only one item.
5. Open the Mods tab with X, change a switch, close, and check the matching feature. Settings reset on closing Isaac in this version.
6. Check the normal small map loses only its dark frame; expanding the map still works.
7. Use Time Machine at a slot machine or beggar in a cleared room after putting out all fires. Hold toward the machine and check speed-up, then release. A still-burning fire or enemy should stop speed-up. The Time Machine row in Mods shows its latest reason for running normally.

Keep the previous verified package and rollback folders until these checks pass.
