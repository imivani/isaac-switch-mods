# Iteration 6: what to check on the Switch

Finish or abandon your current run first. Fully close Isaac, install, then
start a **new run**.

1. **Game starts normally** and the Mods list (X on the main menu) still shows
   all 13 mods.
2. **Item picker** (hold both sticks + D-pad Down in a cleared room):
   - Place **Jupiter**, pick it up: you gain the containers and heal 2 hearts.
   - Place **Void**: its description shows quality 3 and 4 room charges; it
     recharges after 4 cleared rooms.
   - Place **Butter Bean**: "Recharges in 2 seconds", and it does.
   - Place **The Bean**: usable again 4 seconds after use, not after a room.
   - Place **Revelation**: flight and the beam, but no soul hearts.
   - Place **Lil Delirium** + two other baby familiars: Conjoined triggers.
     Lil Delirium's description shows the Conjoined icon.
3. **Descriptions** show the new quality numbers (for example Rock Bottom 4,
   Abyss 3).
4. **Specialist Dance** now starts beside Rock Bottom and no longer beside
   Void or Abyss.
5. **Normal play**: a couple of floors, a Devil room if you get one, a Greed
   Mode run if you like. Nothing should crash or look different apart from
   the balance changes.

If something is wrong, note what you did and what you saw. The installer keeps
the previous module and lists how to undo the four new data files in the
deployment record's `ROLLBACK.md`.
