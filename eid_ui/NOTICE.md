# Original EID artwork and font

The font sheets, inline icons, player icons, transformation icons, card and pill
icons, and related source animation files come from **External Item
Descriptions** by **wofsauge and contributors**:

- Source: https://github.com/wofsauge/External-Item-Descriptions
- Pinned revision: `8b59d00c6828e333294639ad2b2b6875eae821cb`
- Original credits: `UPSTREAM-CREDITS.md`, copied unchanged from that revision.
- File provenance and checksums: `assets-manifest.json`.

The copied PNGs are unchanged source images. The generated font animation and
metric table describe glyph locations in those original font sheets. The new
item-picture animation is a small runtime wrapper for existing game artwork.

As recorded in `../eid/THIRD_PARTY_NOTICES.md`, the pinned EID checkout contains
no LICENSE or COPYING file. These local files preserve upstream attribution and
do not assert a new license over upstream text, artwork, or fonts. This work has
not published or uploaded those files.

The standalone preview may display locally available game item thumbnails, but
the staged resource folder does not contain extracted game item images or the
game's controller art. Runtime item images and controller icons are read from
the installed game.
